# AI-Powered Tourist Transportation and Travel Planning System for Sri Lanka

## Description

A final-year software engineering project that helps tourists plan trips in Sri Lanka using AI-powered transportation and travel planning features.

## Main Features

- Tourist registration and login
- Destination browsing
- Vehicle browsing and booking
- AI vehicle recommendation
- AI travel budget estimation
- Dijkstra-based route optimisation
- Vehicle provider management
- Booking management
- Tourist reviews

## Technologies

- ASP.NET Core MVC (.NET 8)
- C#
- SQL Server
- Entity Framework Core
- Python
- FastAPI
- Scikit-learn
- Random Forest
- Linear Regression
- Dijkstra Algorithm
- HTML, CSS, JavaScript and Bootstrap

## AI Components

### Vehicle Recommendation
Random Forest classification is used to recommend a suitable vehicle based on tourist requirements.

### Budget Estimation
Linear Regression is used to estimate the expected travel cost.

### Route Optimisation
Dijkstra's algorithm is used to calculate the shortest route between selected locations.

## Project Structure

- `AITouristTransport` - ASP.NET Core web application
- `AI-Service` - Python AI service
- `Dataset` - Datasets, training scripts and trained models
